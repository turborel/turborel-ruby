# Appendix D: Versions

[Contents](README.md)

The driver's version is the turborel release it is made for, the same number as the server's: the alpha is 0.0.0, as turborel's is, and speaks the native protocol's version 1 ([VERSIONING.md](../../VERSIONING.md)). This appendix will list each release and the protocol it speaks, once there are releases.
